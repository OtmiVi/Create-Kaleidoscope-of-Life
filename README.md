# test-tkali

A Minecraft modpack backup for **Minecraft 1.21.1**, **NeoForge 21.1.263**, and **Java 21**.
Mods are stored directly in Git as JAR files.

This repository includes:

- `mods/` — installed mods, including the custom Fishing Net Starcatcher Fix.
- `config/`, `defaultconfigs/`, `options.txt` — mod settings, game settings, and key bindings.
- `kubejs/` — KubeJS scripts, assets, and data.
- `resourcepacks/`, `shaderpacks/`, `moonlight-global-datapacks/` — resource packs, shaders, and data packs, when installed.
- `schematics/` — schematics, if present.
- `scripts/`, `docs/` — additional scripts and documentation, if present.

Worlds (`saves/`), screenshots, Xaero maps and waypoints, command history, player data,
logs, caches, disabled mod backups, all `local/` directories, and the standalone
`fishing-net-starcatcher-fix/` directory are excluded by `.gitignore`.
The files `config/resourceful-config-web.json` and `kubejs/config/web_server.json`
are also excluded because they contain local authentication credentials and are regenerated by the mods.
Git does not track empty directories.

## Save changes

Close the game first to prevent configuration files from changing while you save.
Run these commands in the modpack directory:

```powershell
git status --short
git add .
git commit -m "Save modpack"
```

After connecting your remote repository, push the current branch for the first time:

```powershell
git push -u origin HEAD
```

For later updates, run `git add .`, `git commit -m "Update modpack"`, and `git push`.
Check `git status` before committing, especially after installing new mods.
New directories at the instance root must be explicitly allowed in `.gitignore`.

## Restore the modpack

1. Create a Minecraft 1.21.1 instance in your launcher with NeoForge 21.1.263 and Java 21.
2. Close the game and copy the repository files into that instance directory.
3. Use a clean instance for an exact restore to avoid leaving extra mods from an older installation.
4. Launch the game. The launcher, Java, and Minecraft libraries must be installed separately.

Transfer world saves and personal maps separately.
